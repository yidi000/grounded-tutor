# 桌面资料导入与学习工作台：本轮实现记录

日期：2026-09-08。本文记录本轮已实现行为及验证结果，不新增产品需求或未来功能承诺。

## 用户需求与范围

1. 设置的选中、禁用状态要清晰；自定义分隔符及问答提取要求应说明如何启用、如何填写。
2. 导入失败后保留当前步骤、资料输入和处理设置，允许恢复重试。
3. 消除页面上重复的上传入口。
4. 界面更清晰、有设计感，并使用 Impeccable 审查。

本轮范围为桌面本地学习工作台，验证视口为 1280×720、1440×900。不包含移动端、深色模式、登录或未来功能占位，不涉及私有用户资料的修改。

## 已实现的桌面方向

采用 Operate 模式：左侧学习主题、中央对话与输入、右侧资料或回答依据。正文及界面标题统一使用 Noto Sans SC；代码、技术位置等用途保留等宽字体。白色中央内容面与蓝灰侧栏形成层次，蓝色用于主要动作、焦点和选中状态，引用保留现有语义色。

已有可用资料时，主题名称显示为紧凑标题（24px），其下简述资料数量与核对位置。主要上传入口统一为右上角“添加资料”；点击后选择上传文件或粘贴文本。主题介绍、输入框和资料栏不再各放一组常驻上传按钮；文件拖入仍可启动导入，缺少依据时的上下文恢复动作仍可添加资料。

右侧“回答依据”和“全部资料”可切换。点击回答中的引用显示资料片段和原始位置，选中态与关闭控件可见。此方向是根据当前任务直接实施的代码结果，没有用户批准的视觉 comp，因此不作设计稿一致性声明。

## 设置与错误恢复

- 设置摘要显示实际保存方式及系统推荐/自定义状态。推荐模式禁用分段方式、片段长度及索引内容长度，并明确提示由系统控制。
- 自定义分隔符仅在“自定义”且“按指定分隔符”时启用，说明必填、最多 20 字符，并提供与资料标记一致的示例。
- 问答提取要求仅在“问答对”保存方式启用，明确可选、留空使用默认要求；禁用时说明启用方法。
- 禁用使用真实表单 disabled 属性、蓝灰表面及文字说明。帮助通过可访问描述关联字段，补充设置建议可展开。无效值保留在原表单中，显示字段错误并聚焦相应输入。
- 校验错误自动展开高级设置，并通过 effect 将展开状态保留；修改字段清除错误后不会立即折叠，避免输入第一个字符就丢失正在编辑的表单。相应单测增加了从折叠状态触发错误、清除字段后仍可见的断言。
- 切换到系统推荐时，提交忽略未生效的缓存自定义值；切回自定义仍保留此前输入。资料名称与内容的验证失败也留在当前步骤。
- 资料向导标题、步骤与关闭按钮固定，长设置内容在主体内滚动。导入失败保留预计片段步骤；“返回重试”先恢复预览，用户再次确认后才发起导入。实际复核失败保留复核步骤，并可恢复读取结果。
- 实际处理结果为空时解释可能仍在处理，提供刷新及调整设置，禁用“接受并用于问答”。

## API 与本地预览事实

FastGPT 默认 HTTP 客户端读取和写入超时调整为 30 秒，连接与连接池等待仍为 5 秒；没有新增自动重试。错误日志仅记录安全的 failure category，不记录原始资料、凭证或响应正文。

原先的 502 在本轮未能复现，因此不能确证其根因，也不能把超时调整表述为已证明修复该原始故障。

auto 模式的本地片段预览忽略缓存的 custom 分段设置，采用本地默认规则，片段长度默认 1000。前端提交同样归一化未生效的自定义值。该预览是本地估算，不是云端权威分块；用于问答前仍需复核实际处理结果。
