# Original RAG demonstration material

These two short documents were newly authored for the Grounded Tutor demonstration.
They contain no uploaded course materials, private account data, or copied source
passages. The workshop scenarios are invented examples.

To the extent copyright applies, the project contributors dedicate these two
sample documents to the public domain under CC0 1.0 Universal:
https://creativecommons.org/publicdomain/zero/1.0/
This dedication applies to the sample documents, not to the application's code.

`manifest.json` lists the documents and SHA-256 hashes for byte-level integrity.
Create a local Workspace, import the Markdown files or paste their contents,
review processing, and accept the sources before asking grounded questions.
Try "What is a reranker unable to recover?" and "What room is the workshop in?".
The second question intentionally lacks supporting evidence.

These are educational fixtures, not measured evaluation results or an automatically
provisioned cloud dataset. Importing them in live mode uses your configured service.
