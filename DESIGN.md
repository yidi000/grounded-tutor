# Grounded Tutor — Limestone and Burgundy

Approved 2026-09-08: persistent topic navigation and paired conversation/evidence
columns (concept A), with the editorial reading treatment of concept B, palette 2.

Desktop Operate/Read surface, minimum supported width 1280px. Existing learning,
source review, history and citation behavior remains authoritative. No decorative
mode tabs: learning/checks continue through the existing contextual workflow.

## Visual contract

- Canvas #F5F3F0, paper #FCFBF9, ink #302C2D, burgundy #713E4B.
- Citation tint #EFE6E8; quiet rules #DFD9D5. Green/red retain semantic meaning.
- Self-hosted Noto Serif SC 600 for headings/questions; Noto Sans SC for body/UI.
- Persistent shallow topic rail, reading spread divided by a fine rule.
- Answers are readable text, not colored bubbles or nested cards.
- Accent appears on actions, selected topics, citations and keyboard focus.
- Compact 4px controls; no ornamental gradients, heavy shadows or fake features.
- Source wizard, disabled controls, recoverable failures and learning activity
  share the same palette and font roles. Preserve explicit state text and focus.

## Verification scope

Desktop 1280×720 and 1440×900. Check upload/review/accept, saved chat and citations,
learning/recovery, keyboard focus, failed import and disabled settings. Static
public demo remains read-only. Mobile and online accounts are outside this release.
